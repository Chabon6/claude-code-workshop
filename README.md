## Website

網站入口：`index.html`

此頁已加入：

```html
<meta name="robots" content="noindex,nofollow,noarchive">
```

這可以降低被搜尋引擎索引的機率，但**不是存取權限控制**。

## GitHub Pages 部署

1. Repository → **Settings** → **Pages**
2. 在 **Build and deployment** 將 Source 選成 **Deploy from a branch**
3. Branch 選 **main**，folder 選 **/(root)**
4. Save
5. 等 GitHub 完成部署後，Pages 頁面會顯示網站 URL

> 注意：Private repository 不代表 Pages 網站一定是 private。若需要真正登入授權才能查看，必須使用支援 private Pages 的 GitHub Enterprise Cloud 設定，或改用其他具存取控制的 hosting。
